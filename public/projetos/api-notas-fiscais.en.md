# Invoice API

A REST API for requesting and issuing invoices. I built it as a technical assignment for a Node.js software engineer role.

TypeScript from end to end, Prisma over PostgreSQL, input validation with Joi and key-based authentication on the protected endpoints.

I also wrote the tests with Jest and Supertest, documented it in Swagger and left a `docker-compose` that brings the app up behind nginx, with CI on GitHub Actions. It took longer than the assignment asked for, but that is how I like to hand things over.
