# Vapor, Game Store

A digital game store inspired by Steam. We built it as a team, from the Figma layout through to deploy.

The front-end has infinite scroll on the storefront, a promotions carousel, a product page and a cart. The cart keeps its state in localStorage, so the purchase carries on where it stopped if someone closes the browser.

On the back, a Node.js and Express API over MongoDB, with JWT authentication and Joi validation.

Code in two repositories: [front-end](https://github.com/VictorMotta/VaporFrontEnd) and [back-end](https://github.com/VictorMotta/VaporBackEnd).
