# API de Notas Fiscais

API REST para solicitar e emitir notas fiscais. Fiz como teste técnico para uma vaga de engenheiro de software Node.js.

TypeScript do começo ao fim, Prisma sobre PostgreSQL, validação de entrada com Joi e autenticação por chave nos endpoints protegidos.

Também escrevi os testes com Jest e Supertest, documentei em Swagger e deixei um `docker-compose` que sobe a aplicação atrás do nginx, com CI no GitHub Actions. Levou mais tempo do que o teste pedia, mas é assim que eu gosto de entregar.
