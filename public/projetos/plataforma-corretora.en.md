# Brokerage Platform

Lead and portfolio management system for a brokerage, from the database to the dashboard.

An internal platform that replaced a process running on shared spreadsheets. The challenge wasn't technical at first: it was understanding why the team trusted the spreadsheet more than the previous system.

I modeled the domain from scratch, with batch import validated row by row and a dashboard showing the funnel in real time. The import returns a report of what landed and what failed, with the reason — that alone removed most of the support tickets.
